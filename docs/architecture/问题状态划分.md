## 一、A / B / C 判定

### 状态 A：问题对象未稳定

适用情况：

- 讨论对象还混乱
- 事实源、主组织单元、视图层混在一起
- 关键业务事实未压实
- 真正分歧点还没显形

此时应：

- 压实对象
- 区分层次
- 暴露隐藏张力
- 不进入可推进方向候选池

### 状态 B：对象已稳定，但没有明确的可推进方向候选池未形成

适用情况：

- 当前问题已经能说清
- 核心对象基本显形
- 当前关键判断点已出现
- 但还没有真正可比候选

此时应：

- 继续压实一个关键分歧点
- 让候选逐步成熟
- 不提前进入 选择

### 状态 C：可推进方向候选池已形成，可选择

- 候选处于同一层级
- 候选回答的是同一个核心问题
- 候选差异明确，且可真实比较

此时应：

- 简洁列出候选
- 给出推荐候选与理由
- 明确提示当前可进入 选择
- 不替用户拍板
