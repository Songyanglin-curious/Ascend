
# 生产管控预警前端最小流程文档（简版）

## 1. 目标

只覆盖最小闭环：

 **A 建总单并下发给 B → B 创建任务并下发给 C → C 填报并上报 → B 查看/打回 C 或汇总上报 → A 查看/打回 B → B 重提** 。

不展开：

* 附件
* 复杂权限
* 非主线异常分支
* 页面样式设计

---

## 2. 前端调用规则

### 2.1 请求格式

统一请求地址：

```javascript
fetch('http://10.15.0.77:7032/api/PDP', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    args: [
      // 每个对象就是一次元接口调用
    ]
  })
})
.then(response => response.json())
.then(data => {
  console.log('Success:', data);
})
.catch(error => {
  console.error('Error:', error);
});
```

### 2.2 元接口规则

* `load`：读取， **对象传参** ，字段名用 `xml`
* `read`：读取， **数组传参** ，字段名用 `sql`
* `modify`：修改，字段名用 `sql`
* `new`：新增，字段名用 `sql`，一般返回自增 ID。

### 2.3 引用上一条新增返回的自增 ID

```javascript
{ ref: "0", value: -1, type: "string" }
```

表示引用本次 `args` 数组中第 `0` 个调用返回的自增 ID。
你现在实际使用里也已经这样跑通了。

## 3. 当前最小对象

前端只需要先知道这些主对象：

* 总单：`jb_production_main_order`
* A→B 下发：`jb_production_main_order_assign`
* 任务：`jb_production_task`
* 任务角色：`jb_production_task_actor`
* 角色日报：`jb_production_task_actor_report`
* B 当日上报：`jb_production_b_daily_submission`
* B 上报关联：`jb_production_b_daily_submission_actor_report_rel`。

### A 侧

### B 侧

### 5.12 B：被 A 打回后重新上报

#### 接口

* `DeleteTaskActorReportsByBDailySubmission`
* `InsertTodaySubmittableActorReportsToRejectedBDailySubmission`
* `ResubmitBDailySubmission`。

#### 规则

1. 删除旧关联
2. 重新挂接今天可报日报
3. 再重提。


## 6. 前端最重要的 4 条规则

### 6.1 C 填报先查详情，再决定新增还是更新

* `report_id` 为空：`CreateTaskActorReportForToday`
* `report_id` 不为空：`UpdateTaskActorReportForToday`。

### 6.2 C 的保存、完成、上报可以都走同一个更新接口

通过 `state` 控制：

* `CREATED`
* `DONE`
* `SUBMITTED`。

### 6.3 B 的“今日上报”是自动收集

不是手工勾选，而是自动挂接今天全部 `SUBMITTED` 的角色日报。

### 6.4 A 打回 B 时不清关联

真正清旧关联发生在  **B 重提之前** 。

## 7. 给前端的最小实现建议

前端页面动作不要完全等于单接口动作，建议组合成下面这些按钮或页面行为：

* A：创建并下发
* B：完成任务下发
* C：进入详情并填报
* C：保存 / 完成 / 上报
* B：今日上报
* A：打回 B
* B：重新上报。

**前端现在可以按“A建总单并下发 → B建任务并挂角色 → C填报并上报 → B查看/打回/上报 → A查看/打回 → B重提”的顺序实现最小闭环，元接口调用规则和关键示例已经具备直接落地条件。**
