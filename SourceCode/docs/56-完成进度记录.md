# 56-完成进度记录

这份文档只记录当前 1.0 的完成范围和最近收口结果，避免继续扩展叙事。

## 当前已完成范围

- 最小内核：`Tree / Node / StepRecord`
- 上层主链：`Solution / Workspace / Project / Round`
- 最小节点工作流：`new-node`、`focus-node`、`step`、`finish-node`
- 最小 AI 接入：`step-ai`、`step-draft`、`finish-ai`、`ai-step --dry-run`、`ai-draft`
- CLI 主入口与旧别名兼容
- 最小运行骨架：`npm start`
- 最小测试骨架：`npm test`

## 当前可用能力

- 可以初始化最小状态
- 可以查看状态、列出节点、查看单节点详情
- 可以在当前焦点节点上执行最小推进
- 可以预览 AI 草稿而不落盘
- 可以用 DeepSeek 为 step 或 finish 生成草稿，再进入现有流程
- 可以结束节点，并把 `summary / conclusion` 写回节点
