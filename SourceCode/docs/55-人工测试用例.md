# 55-人工测试用例

这份文档用于人工复核当前 1.0 的 CLI、落盘和 DeepSeek 接入，不扩展能力边界。

## 覆盖范围

- CLI 主入口：`init`、`reset`、`status`、`show-state`、`nodes`、`node <nodeId>`、`step`、`step-ai`、`step-draft`、`new-node`、`focus-node`、`finish`、`finish-ai`
- 旧别名兼容：`list-nodes`、`show-node <nodeId>`、`ai-step`、`ai-step --dry-run`、`ai-draft`、`finish-node`、`finish-node --ai`、`ai-finish`
- 落盘行为：状态文件、`stepRecords` 历史、节点结束后的 `summary / conclusion`
- DeepSeek 实调用前置检查：配置文件、API key、模型名、接口地址、缺 key 报错
- 关键路径：`step`、`step-ai`、`step-draft`、`finish`、`finish-ai`

## 建议人工检查项

1. `npm run cli -- reset` 后，`status` 和 `show-state` 读取的是同一份状态文件。
2. `npm run cli -- nodes` 能按树层级打印节点，并标出当前焦点。
3. `npm run cli -- node node-1` 能打印节点详情和关联 `stepRecords`。
4. `npm run cli -- step` 会追加 `stepRecords`，不会覆盖历史。
5. `npm run cli -- finish-ai node-1` 会先生成收尾草稿，再进入结束流程。
6. `npm run cli -- ai-step --dry-run` 和 `npm run cli -- step-draft` 只预览，不落盘。
7. 无 `DEEPSEEK_API_KEY` 时，`step-ai` / `finish-ai` 会给出清晰中文错误。

## 建议记录格式

- 命令
- 预期输出
- 实际输出
